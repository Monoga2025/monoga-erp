# test

Vitest suites for Monoga ERP.

- Store and adapter unit tests: `metadata-store`, `youtube-adapter`, `viral-scripts-adapter`, `workspace-*`, `jarvis-telemetry`.
- Module tests: `event-sales`, `catalog-search`, `prompts-store`.
- API route tests: `api-*.test.ts` and `app.test.ts`.
- UI shell and content tests: `admin-dashboard-*` and `web-ui`.
- Run with `npm test` from the repo root.
