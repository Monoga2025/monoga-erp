# src/client

React and Vite admin UI.

- `App.tsx`: tab switching between dashboard, sources, YouTube cases, search and Jarvis HUD.
- `components/`: admin shell, Jarvis omnibar and dashboard widgets.
- `views/`: one component per tab.
- `data/dashboardDemoData.ts`: demo data used by the dashboard.
- Served by the Fastify server from the built output.
